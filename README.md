  ↳ `Word2Vec` `Feature Engineering` `Neural Networks`

- **[Vampires vs Werewolves](https://github.com/Vaios-Panagiotou/Vampires-vs-Werewolves)** — Developed a turn-based strategy game with terminal and SDL2 graphical interfaces, custom pathfinding, and a day-night cycle.
